# Cyberking 3D

Эксперимент: 15-секундная сцена боя в 3D по мотивам игры Cyberking. Кибергоплит с копьём и щитом против Луны, третьего стража короля.

Всё сделано кодом на three.js: модели, позы и анимация, эффекты, камера и звук. В проекте нет готовых моделей, текстур и записанных звуков.

## Как посмотреть

Откройте `index.html` в браузере. Нужен интернет: библиотека three.js загружается с CDN.

Чтобы страница открывалась по ссылке, включите GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Адрес страницы GitHub покажет там же.

## Управление

| Что | Мышь или палец | Клавиша |
|---|---|---|
| Смотреть и пауза | кнопка «Смотреть» | пробел |
| Кадр назад и вперёд | кнопки `‹` и `›` | `←` и `→` |
| Перемотка | полоса времени | |
| Камера фильма или своя | «Кино» и «Своя» | `C` |
| Скорость | `1×`, `½`, `¼` | |

Своя камера работает и на паузе, и во время боя:

- тянуть: вращать камеру;
- колесо или щипок: приблизить и отдалить;
- правая кнопка мыши или два пальца: сдвинуть.

Кнопки «Вести» ставят камеру на готовый ракурс, и дальше она едет за бойцом. Повторное нажатие оставляет камеру стоять на месте.

Что стоит знать:

- На замедлении фильм идёт без звука.
- Своя камера показывает то, что киношная прячет. Например, на склейке в 3,6 с гоплит переносится на новое место.
- В своей камере отключены затемнения в начале и в конце и силуэтный свет финала, чтобы бойцов было видно с любой стороны.

## Что где лежит

```
index.html            готовая страница с плеером (собирается из scene3d)
scene3d/src/          сцена и фильм
  lib.js              помощники: материалы, гранёные детали, обратная кинематика, обводка
  world.js            крыша замка: небо, луна, зеркальный пол, башни
  hoplite.js          модель гоплита и функция, которая ставит его в позу
  luna.js             модель Луны, катана и ножны
  fx.js               искры, серпы, вспышки, следы клинка
  film.js             позы, раскадровка по времени, камера, свет
  events.js           общие моменты времени для картинки и звука
  main.js             рендер и плеер
  page.html           вёрстка плеера
scene3d/*.cjs         сборка, рендер кадров, проверки
sfx/                  синтез звуков и сведение дорожки
storyboard/           раскадровка-комикс первой версии сцены
```

Фильм — чистая функция времени: `film.update(t)` ставит обоих бойцов, эффекты, свет и камеру в состояние на момент `t`. Поэтому перемотка, покадровый шаг и рендер в файл дают одну и ту же картинку.

## Сборка

Нужны Node.js 18 или новее и ffmpeg. Для рендера кадров и проверок нужен Playwright с Chromium.

```bash
cd scene3d
npm install
npx playwright install chromium
```

Собрать страницу после правок в `scene3d/src`:

```bash
node scene3d/build.cjs --site
```

Проверить плеер (игра, перемотка, шаг по кадрам, своя камера):

```bash
node scene3d/playtest.cjs
```

Пересобрать звук после правок в `sfx` или в `events.js`:

```bash
node sfx/mixfilm.cjs
ffmpeg -y -i sfx/out/film.wav -c:a libmp3lame -b:a 160k scene3d/audio.mp3
node scene3d/build.cjs --site
```

Снять видео 1080p, 30 кадров в секунду:

```bash
cd scene3d
node render.cjs 1920x1080 30 final 3
ffmpeg -framerate 30 -start_number 0 -i final/f%05d.jpg -i ../sfx/out/film.wav \
  -vf "scale=in_color_matrix=bt601:in_range=full:out_color_matrix=bt709:out_range=tv,format=yuv420p" \
  -c:v libx264 -preset slow -crf 15 -color_range tv -colorspace bt709 -color_primaries bt709 -color_trc bt709 \
  -c:a aac -b:a 256k -ar 48000 -movflags +faststart -t 15.4 hoplite-vs-luna.mp4
```

Скрипты рендера и проверок запускают браузер с программной отрисовкой, потому что писались на сервере без видеокарты. На обычном компьютере флаги `--use-angle=swiftshader` и `--enable-unsafe-swiftshader` в них можно убрать, и рендер пойдёт заметно быстрее.

Другие полезные скрипты:

- `scene3d/frames.cjs` собирает лист кадров в выбранные моменты, чтобы просмотреть позы.
- `scene3d/armcheck.cjs` ищет кадры, где рука уходит внутрь корпуса.
- `scene3d/sitetest.cjs` проверяет, что `index.html` запускается сам по себе.
- `sfx/buildpage.cjs` собирает страницу, где каждый звук можно послушать отдельно.

## Откуда персонажи

Гоплит и Луна — персонажи игры Cyberking. Здесь они перерисованы с нуля в 3D; графика и анимации самой игры не использованы.
