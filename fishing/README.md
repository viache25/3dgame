# Бешеный клёв

Аркадная 3D-рыбалка. Катер в лагуне, минута на часах. Видишь рыбу в воде — кидаешь блесну прямо в неё, тащишь в катер и сразу ищешь следующую. Ожидания поклёвки нет.

Всё сделано кодом: модели, вода, небо и звук. Готовых ассетов нет.

## Как играть

Откройте `index.html` в браузере. Нужен интернет: three.js загружается с CDN.

| Что | Мышь и клавиатура | Телефон |
|---|---|---|
| Заброс в точку | щелчок по воде | ткнуть в воду |
| Заброс в ближайшую рыбу | пробел | |
| Тянуть рыбу | держать кнопку мыши или пробел | держать палец |
| Катер | `WASD` или стрелки | левый палец внизу слева |
| Пауза | `Esc` или `P` | |

Что стоит знать:

- Блесна, упавшая прямо на рыбу, цепляет её сразу и удваивает очки. Упавшая рядом — подманивает ближайшую.
- Килька идёт без борьбы. Дорадо, меч-рыба и золотая рыбка делают рывки: рыба мигает красным, надпись меняется на «ОТПУСТИ!». Тянуть в рывок нельзя, леска рвётся.
- Нажать сразу после рывка — «Чётко!»: рыбу подбрасывает на несколько метров ближе.
- Каждый улов добавляет секунды. Уловы подряд дают множитель до x8, обрыв его сбрасывает.
- Катером можно догонять рыбу, чтобы леска не вытянулась на всю длину.
- Акула идёт за рыбой на леске и съедает её. Акулу можно таранить катером на ходу: +150.
- Когда время вышло, рыбу на леске дают дотащить.

## Что где лежит

```
index.html        готовая страница (собирается из src)
src/
  world.js        небо, вода, острова, буи, свет
  models.js       рыбы, акула, катер с рыбаком и удочкой
  fx.js           брызги, круги на воде, леска
  audio.js        звуки из шума и осцилляторов
  game.js         цикл, заброс, борьба, акула, часы, камера, интерфейс
  page.html       вёрстка и стили
build.cjs         сборка страницы
test/play.cjs     проверка в браузере
```

## Сборка и проверки

Нужен Node.js 18 или новее и Playwright с Chromium.

```bash
cd fishing
npm install
node build.cjs     # out/game.html (фрагмент для публикации) и index.html
npm test           # сборка и проверка на размере компьютера и телефона
```

`test/play.cjs` открывает страницу в браузере без видеокарты и проходит заход: заброс настоящим нажатием, вываживание, рывок дорадо, обрыв, акула, таран, конец времени, новый заход. На размере телефона (`PHONE=1`) нажатия делаются настоящими касаниями, в том числе двумя пальцами сразу. Кадры каждого шага ложатся в `out/`. Проверка падает на любой ошибке страницы.

Плавность на настоящем устройстве и звук эта проверка не видит.
