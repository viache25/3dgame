# Клинок и глина

Прототип слэшера. Странник с раскалённым клинком против глиняных идолов на соляной равнине. Главное в нём одно: разрез проходит ровно по линии, которую ты провёл, и всё, через что она прошла, честно разваливается на части. Части можно резать дальше.

Вселенная и вид здесь черновые, они нужны, чтобы было что резать. Никаких готовых моделей, текстур и записанных звуков нет, всё сделано кодом.

## Как играть

Откройте `index.html` в браузере. Нужен интернет: three.js загружается с CDN.

| Что | Мышь и клавиатура | Телефон |
|---|---|---|
| Разрез по линии | провести мышью с зажатой левой кнопкой | провести пальцем |
| Быстрый удар по ближнему | щелчок | коснуться |
| Бег | `WASD` или стрелки | левый палец |
| Рывок | пробел | кнопка «Рывок» |
| Замедлить время | держать `Shift` или правую кнопку | кнопка «Фокус» |
| Пауза | `Esc` или `P` | |

Что стоит знать:

- Если линия далеко, странник сам делает выпад к ней, до 3,8 м.
- Резкий поворот в одном длинном росчерке начинает новый разрез, поэтому каракули рубят в крошку.
- Идол погибает, когда разрез проходит через туловище, голову или ногу. Руку или занесённый кулак можно отрубить отдельно, идол при этом жив.
- Фокус тратится, пока время замедлено, и возвращается за каждого сражённого.
- Колонны, кувшины и тростник тоже режутся. Верх колонны съезжает по срезу.

## Как устроена резка

1. Росчерк на экране задаёт плоскость: она проходит через глаз камеры и два луча, начало и конец линии. Поэтому на экране срез совпадает с нарисованной линией.
2. Каждая фигура собрана из выпуклых кусков. Выпуклый кусок плоскость делит ровно на два выпуклых, и на месте среза появляется новая грань.
3. После разреза куски собираются в группы по тому, что ещё держится друг за друга. Через плоскость разреза ничего не держится, кроме куска, до которого клинок не достал.
4. Каждая группа становится твёрдым телом: падает, кувыркается и ложится на песок. Верхняя часть сначала едет по плоскости среза.
5. Свежая грань светится и остывает за несколько секунд.

Тела друг с другом не сталкиваются, только с землёй. Это главное упрощение прототипа.

## Что где лежит

```
index.html        готовая страница (собирается из src)
src/
  geo.js          выпуклые куски: построение, разрез плоскостью, объём, группы
  phys.js         твёрдые тела: падение, опора на землю, скольжение по срезу
  render.js       сетки из кусков, свечение срезов, искры, пыль, след клинка
  models.js       странник, идолы, клинок, колонны, кувшины, тростник
  world.js        равнина, небо, свет
  audio.js        звуки из шума и синусов
  game.js         цикл, росчерк и разрез, идолы, волны, камера, интерфейс
  page.html       вёрстка и стили
build.cjs         сборка страницы
test/             проверки
```

`geo.js` и `phys.js` не зависят от three.js и от браузера, их проверки идут в Node.

## Сборка и проверки

Нужен Node.js 18 или новее. Для проверки в браузере нужен Playwright с Chromium.

```bash
cd slasher
npm install
```

Собрать страницу после правок в `src`:

```bash
node build.cjs
```

Проверить всё:

```bash
npm test
```

Что проверяется:

- `test/geo.test.cjs`: объём сохраняется после 60 случайных разрезов, куски остаются замкнутыми и выпуклыми, группы собираются правильно.
- `test/phys.test.cjs`: брошенные куски ложатся на землю и засыпают, верхняя часть съезжает по срезу.
- `test/play.cjs`: страница открывается в браузере без видеокарты и проходит бой. Разрез идола, движение настоящей мышью и клавишей, отрубленный кулак, рубка в замедлении, колонна, удар по страннику, поражение. Кадры каждого шага ложатся в `out/`.

Та же проверка на размере телефона, с настоящими касаниями двумя пальцами:

```bash
PHONE=1 node test/play.cjs
```
